【音樂資料夾說明】

本資料夾需要放入背景音樂檔案：beat.mp3

====================
【音樂規格建議】
====================
- 檔案名稱：beat.mp3 (必須)
- 檔案格式：MP3 (推薦) 或 WAV
- 時長：至少 24 秒
  (每張圖片 1 秒 × 24 張圖片 = 24 秒)
- BPM：60 BPM (每分鐘 60 拍)
  → 每秒 1 拍，與圖片切換同步
- 音量：中等音量（程式中設為 50%）
- 風格：節奏明確、穩定的背景音樂

====================
【免費音樂資源】
====================
1. Freesound (https://freesound.org/)
   - 免費音效與音樂素材
   - 搜尋關鍵字: "beat", "rhythm", "60 bpm"

2. Incompetech (https://incompetech.com/)
   - Kevin MacLeod 免費音樂庫
   - 可按 BPM 篩選

3. Bensound (https://www.bensound.com/)
   - 免費背景音樂
   - 適合遊戲使用

4. YouTube Audio Library
   - YouTube 提供的免費音樂庫
   - 可下載 MP3 格式

5. Purple Planet (https://www.purple-planet.com/)
   - 免費遊戲音樂

====================
【如何調整 BPM】
====================
如果你的音樂不是 60 BPM，可以調整程式中的節拍間隔：

在 app.py 中修改：
  "beatInterval": 1000  # 1000 毫秒 = 1 秒

計算公式：
  beatInterval (毫秒) = 60000 / BPM

範例：
  - 60 BPM → 60000 / 60 = 1000 毫秒
  - 120 BPM → 60000 / 120 = 500 毫秒
  - 90 BPM → 60000 / 90 = 667 毫秒

====================
【快速測試】
====================
如果暫時沒有音樂檔案：
1. 遊戲仍可正常運作（只是沒有音樂）
2. 瀏覽器 Console 會顯示音樂載入失敗的警告
3. 可以先用其他 MP3 檔案重新命名為 beat.mp3 測試

====================
【音樂播放機制】
====================
- 點擊「Start Game」後自動播放
- 遊戲結束後自動停止
- 支援靜音切換（點擊「音樂」按鈕）
- 音樂只會播放一次，不會重複
- Round 切換時音樂繼續播放（不中斷）

====================
【注意事項】
====================
⚠️  現代瀏覽器的自動播放政策：
   - Chrome/Edge: 需要使用者互動才能播放音樂
   - 如果自動播放被阻擋，會出現提示
   - 解決方案：點擊「音樂」按鈕手動開啟

⚠️  音樂檔案大小：
   - 建議 < 5MB，確保快速載入
   - 太大的檔案會影響遊戲載入速度

⚠️  支援的瀏覽器：
   - Chrome、Firefox、Safari、Edge 都支援 MP3
   - 建議使用最新版本瀏覽器
